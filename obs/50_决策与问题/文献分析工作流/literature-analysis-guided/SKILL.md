# 引导式工程文献分析

## 目标

围绕用户本轮真正要回答的问题组织阅读，不以覆盖全文为目标堆积信息。翻译、论文事实、作者解释、工程推断和用户决策必须分层，任何扩展分析先经过用户裁决。

当前若从 `50_决策与问题` 中加载本 skill，应将其视为候选流程；只有经过用户确认与更多样本文献复核后，才可升格为稳定 skill。

## 当前用户已确认的个人默认

- 英文文献默认交付“完整中文阅读版 + 定向分析”，当轮明确要求可覆盖该默认。
- 具有复用价值的低阶模型可以形成 L1 单源证据和方法候选，但不得自动进入 MATLAB/Simulink 实施。
- 次要机理争议可以审计，但除非会改变核心结论，不得挤占主论证链。
- 面向飞控的控制分析可深入到时间尺度、受影响通道、前馈/观测/调度架构、不确定度和验证工况；无闭环证据时不得给出增益、带宽或阈值。
- 用户已明确降权的精度比较只给定性和大概范围，不为完整感扩大篇幅。
- 方法对比型论文先提取不同方法共同支持的物理现象、显著趋势和是否违背常识，再讨论方法差异与精度。
- 中文表述保留标准专业术语，但必须写清具体对象、工况、比较基准、数字口径和工程含义，不用未解释的短标签压缩推理链。
- 当前用户的飞行动力学模型默认保留转周平均、准定常或缓慢变化的气动力；旋翼转速倍频等高频短周期项作为论文事实和被忽略效应记录，不默认进入显式模型。只有结构载荷、振动、执行机构 RMS、传感器混叠/滤波、高带宽控制或当轮明确要求命中时才展开。

## 工作流

### 1. 冻结本轮问题

在深入阅读前写明：

- 用户角色与使用场景；
- 本轮要回答的 3–5 个问题；
- 明确不在范围内的内容；
- 什么情况必须暂停并请求用户判断。

若用户关注机理、建模或控制，不因论文篇幅较多就默认展开数值算法、文献综述或全部公式。若认为范围过窄会漏掉影响结论成立性的内容，只提出理由和最小扩展建议，待批准后再做。

### 2. 建立来源基线

优先以 PDF 为证据主源，Markdown 为检索和编辑辅助。记录题名、作者、年份、版本、文件路径与哈希；核对 PDF 页数、图表、公式和附件是否完整。

发现 Markdown OCR、表格、图像、页码或符号表错位时，以 PDF 物理页序及图号、表号、公式号重建锚点。不得把来源包目录名误认为研究对象或构型。

### 3. 选择翻译产品

对本工作区当前用户，英文文献默认同时提供完整中文阅读版和定向分析；当前任务的明确指令优先于这一历史默认。对尚未建立该个人偏好的其他场景，只有用户明确要求全文中文版本时才做全文翻译，否则提供定向中文精读。

全文中文阅读版应：

- 忠实保留正文逻辑、关键公式、图表和限制；
- 统一术语、数学符号、参考位置、方向及总量/分量/增量；
- 修复来源 Markdown 中可由 PDF 核实的抽取错误；
- 把译者说明与作者原文分开；
- 参考文献可保留原文入口，不为完整感重复翻译。

### 3.1 中文清晰表达闸门

中文译文、分析和知识条目均执行以下规则：

- 每个要点只承载一个主要判断。首句直接说明“什么对象在什么条件下发生了什么变化”，证据和适用边界放在同句或紧随下一句。
- 输入包含多个彼此独立的原始判断时，逐条分点改写，不合并成术语和限定条件密集的长段落。
- 专业术语首次出现时，说明它指向的具体物理对象、作用方向或本文含义。保留行业标准术语，但不得用术语串代替物理解释。
- 百分比或“差异”必须写清比较双方、参照分母、统计口径、适用范围和用途。参照量没有说明、数值很小或发生变号时，不给百分比，改报绝对差值并解释原因。
- 不使用未定义的压缩词，例如“宽范围扫描”“基线接近零”“扰动显著”。确需使用时，在同句给出实际范围、所指变量、变化方向和判断依据。
- 保留符号、单位、坐标方向和专业精度。一句话中出现多个陌生术语时，拆成“物理现象—证据—工程含义”，不堆叠术语。
- 每条关键结论应能独立回答：对象是什么、与什么相比、在哪些条件下、如何变化、可以用于什么以及不能用于什么。
- 来源没有说明具体变量、参照状态、分母、统计口径或作用方向时，直接写“来源未说明，当前不能确定”，不得用看似合理的“无干扰基线”“平均值”等词代填。

### 4. 还原文章论证链

先回答“文章如何推进”，再摘要各节。至少识别：

1. 研究缺口；
2. 作者提出的解决办法；
3. 方法可信度如何建立；
4. 核心对照或验证；
5. 从现象到解释的证据链；
6. 作者结论及其适用边界。

### 5. 按证据层抽取

每项重要信息标注为下列一种：

- **论文事实**：工况、图表结果、明确陈述；
- **作者解释**：作者给出的机理或因果归因；
- **工程推断**：结合用户用途形成的建模或控制含义；
- **未知或冲突**：论文未说明、证据不足或不同证据不一致。

工程推断必须说明从哪些证据出发，并禁止改写成作者已经证明的结论。

### 5.1 方法对比论文先提取共性

当论文比较两种计算、试验或建模方法时，先把图表结论分为三类：

1. **两种方法共同支持**：优先进入物理现象和显著趋势；是否进入低阶模型，还必须按用户的模型目标和关注带宽筛选；
2. **只在一种方法中出现**：作为方法特有结果，不改写成普遍机理；
3. **作者声称但证据不足**：保留为审计项，说明缺少的对照、统计或验证。

先回答“共同现象是否符合已有物理认识、是否真的出现反常新结论”，再讨论差异大小和方法精度。比较旋翼对机翼与机翼对旋翼时，必须写明作用方向；一个方向影响较小不能推出反方向也较小。图表只给瞬时样本时，不得整理成平均趋势或倾转角查表。

### 6. 执行信息闸门

一条信息只有影响下列至少一项时，才进入主报告：

- 研究贡献或文章论证；
- 核心方法的输入、输出和流程；
- 模型适用性、假设或边界；
- 证据强度或验证充分性；
- 复现条件；
- 用户当前的工程决策。

主报告默认包含：一句话结论、3–5 条关键结论、文章逻辑、方法输入/输出/流程、机理与现象、适用边界、证据强度、未说明项和待用户确认项。公式展开、原文摘录、数值算法细节和次要结果进入按需附录。没有新增判断时记录 no-change，不为形式完整扩写。

### 7. 应用用户关注镜头

根据用户指定的角色选择主镜头，例如：

- 机理镜头：现象、耦合路径、因果证据与替代解释；
- 建模镜头：输入、状态、输出、动态项、辨识需求和包线；
- 控制镜头：受影响通道、调度变量、扰动结构、带宽分离和验证工况；
- 复现镜头：数值方法、网格、收敛、数据和参数。

未被选中的镜头仅保留足以判断可信度的最少内容。

控制镜头获得“深入”授权时，先按用户实际模型目标和关注带宽确定保留层级，再区分平均/慢变项与旋翼阶次快变项。对当前用户，默认深入平均载荷、慢变残差及其对配平前馈、扰动观测、增益调度、控制分配和控制余量的影响；高频项通常只列为未显式建模的论文现象。只有结构载荷、振动、执行机构 RMS、传感器混叠/滤波、高带宽控制或当轮明确要求命中时，才展开阶次幅相、跟踪或滤波问题。论文没有闭环证据时，只形成架构假设与验证问题。

### 7.1 工程经验值闸门

从单篇论文提取简化建模量级前，必须依次确认：

1. 对比是否是部件 ON/OFF 的纯干扰增量，还是不同建模方法、不同历史或不同相位的综合差异；
2. 数值是瞬时样本、方位同步样本、转周均值还是统计包络；
3. 作为百分比参照的系数是否数值很小或发生变号；若是，改用绝对系数差并说明正负方向，不使用会失真的百分比；
4. 可迁移的是通用系数、当前构型经验带，还是仅用于压力测试的异常样本。

证据不足时，只能发布带有构型、工况、数据口径和禁用用途的 L1“筛选场景”，不得改名为经验定律、标定系数或默认工程参数。

必须把“部件相互作用强弱”和“建模方法精度”视为两个独立比较轴。例如，悬停时机翼对旋翼影响较小，并不能推出准定常方法在悬停或过渡中更准确；除非来源给出相应方法对照或试验验证，不得跨轴替代证据。

### 8. 设置扩展与发布闸门

遇到以下情况必须暂停并请求用户裁决：

- 当前问题或排除项尚未冻结；
- 建议超出用户已批准范围；
- 证据冲突或结论只能依靠推测；
- 某细节是否属于核心结论需要价值判断；
- 准备把一次反馈升格为跨任务偏好或稳定 skill；
- 准备改写既有正文、建立新目录或发布通用工程方法，且当前任务没有对应授权。

### 9. 分层保存

- 单篇论文的译文、证据卡和定向分析跟随来源保存；
- 长任务台账、用户显式决策、偏好候选和 skill 候选保存在 `50_决策与问题`；
- 可复用工程方法按工作区治理规则进入知识维基或审核流程；
- 稳定 skill 只有在用户批准后才安装或发布到 canonical skill 目录。

决策记录只保存脱敏后的抽象条目，包含适用范围、例外、成熟度和确认状态；不得保存完整聊天或推测用户心理画像。

## 质量检查

交付前确认：

- 所有关键判断都有 PDF 物理页序、图、表或公式锚点；
- 翻译没有改变原文的条件词、比较对象或证据强度；
- “准定常”“瞬态”等术语按论文定义，而非按日常含义解释；
- 作者解释与独立证据没有混写；
- 经验量级已区分纯干扰、模型形式差异和瞬时/均值口径；
- 每个百分比均已说明比较对象、参照分母、范围、统计口径和用途；参照量很小或变号时已改用绝对差值；
- 不存在未定义的压缩词或术语堆叠；抽取任一要点，都能复述对象、条件、变化、证据、用途和边界；
- 多个独立判断已逐条分开；缺失的变量、基准或统计口径已明确标成“未说明”，没有由助手补造；
- 方法对比论文已区分“两种方法共同支持、仅一种方法出现、作者声称但证据不足”；
- 已把“来源观察到的物理现象”和“当前模型实际保留的项”分开；高频项若被省略，已明确写成建模取舍而不是物理现象不存在；
- 用户当前关注内容位于主文，非核心细节已压缩；
- 待确认问题是少量、互斥且能改变下一步工作的真实决策点；
- 来源文件未被无意修改，新增文件和链接均可验证。
