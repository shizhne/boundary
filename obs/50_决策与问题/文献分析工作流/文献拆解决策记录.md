# 单篇工程文献示范拆解与偏好校准决策

## 背景

既有 Codex 文献阅读有时不能准确提取用户需要的关键信息、核心方法和重点结论；生成的总结也可能因细枝末节过多而影响阅读。用户决定用一篇文献进行示范性拆解，通过实际取舍逐步校准后续文献分析方式。

## 已确认事实

- 首篇示范文献为 Wu、Li、Cao 2019：*Numerical Simulation of Rotor-Wing Transient Interaction for a Tiltrotor in the Transition Mode*。
- 文献为英文，原始 PDF 与英文 Markdown 均已存在。
- 用户当前角色视角为飞控算法工程师。
- 本篇更偏气动建模，而非控制算法设计。
- 当前任务是长对话，需要持续保存决策与校准结果。

## 决策

| ID | 用户明确决定 | 当前执行方式 |
|---|---|---|
| D-001 | 先获得英文论文的中文版本 | 生成正文基本完整、参考文献不重复翻译的中文阅读版 |
| D-002 | 需要先理解文章按何种逻辑结构推进 | 分析报告先给论证链，再给结论与细节 |
| D-003 | 重点关注机理层、现象层和解释层 | 使用“原始结果—作者解释—工程推断—边界”分层 |
| D-004 | 关注对建模与控制律设计的指导，本文以建模为主 | 重点分析动态载荷结构、输入输出、准定常失效边界与谨慎控制启示 |
| D-005 | 不把数值模拟方法作为主要关注对象 | CFD 细节仅保留判断可信度、假设和复现边界所需部分 |
| D-006 | 非必要不做深入延伸 | 发现值得深挖的问题时只提出建议，获批准后再执行 |
| D-007 | 文献内容与分析过程分层保存 | 译文/单源分析进文献目录；决策/偏好/skill 进本目录 |
| D-008 | 保留需要用户确认的信息 | 报告末尾保留中文粒度、建模深度、机理审计和控制分析粒度问题 |
| D-009 | 后续默认采用“完整中文阅读版 + 定向分析” | 英文文献同时提供可连续阅读译文与按当前工程问题裁剪的分析，不把两者混写 |
| D-010 | 低阶模型做知识库留存，暂不做 MATLAB 实施 | 新建 L1 单源证据与方法候选；本轮不生成脚本、模型或参数文件 |
| D-011 | “倾转惯性/离心效应”和“振荡频率增加”可审计，但不作为核心逻辑 | 在定向分析中保留短小证据审计，避免其主导报告结构 |
| D-012 | 控制律分析进一步深入 | 覆盖时间尺度、受影响通道、前馈/观测/调度架构、不确定度和验证工况；不臆造增益或阈值 |
| D-013 | 准定常与连续瞬态精度影响只需定性和大概范围 | 把精度比较降为边界说明，不将其作为阅读重点 |
| D-014 | 评估论文数据能否形成简化建模经验值 | 允许形成严格标注来源和禁用边界的筛选场景，不预设其一定可作为通用参数 |
| D-015 | 对方法对比论文，先提取两种方法共同支持的物理现象和趋势 | 先按“共同支持—仅一种方法出现—作者声称但证据不足”整理图表，再讨论方法差异和精度 |
| D-016 | 使用专业术语，但必须用清晰完整的中文解释 | 每条关键结论写清对象、工况、比较基准、变化、证据和工程含义；未定义压缩词不得代替推理链 |
| D-017 | 当前建模默认以转周平均或缓慢变化气动力为主，高频短周期气动力权重较低 | 阅读时仍保留旋翼阶次周期波动这一论文事实；建模建议中默认不显式建立该项，只在结构载荷、振动、执行机构 RMS、传感器混叠/滤波或高带宽控制任务中重新评估 |

## 理由

- 中文阅读版解决语言门槛，但不应把译文和助手解释混在一起。
- 文章结构和论证链帮助用户判断每一节为何存在，避免平均总结章节。
- 机理、现象和解释直接服务于飞行动力学建模；求解器细节只有在 CFD 复现任务中才是核心。
- 把用户明确决定与助手推断偏好分开，可以避免把单篇反馈过早固化。
- 论文观察到某个高频现象，不等于当前飞行动力学模型必须显式建立它；模型保留项应按研究目标和带宽另行筛选。

## 放弃的备选方案

- 不采用逐段中英对照翻译：篇幅过长，妨碍连续阅读；原文仍可随时核对。
- 不机械套用现有十段式文献摘要：可能再次造成信息膨胀。
- 不把表 5–8 直接整理为飞行动力学查表数据：取样/平均方法、方位角和过渡试验验证均不足。
- 不在首篇结束后直接发布稳定 skill：单样本容易过拟合。
- 不在本轮直接扩展 MATLAB/Simulink 模型：需要用户先确认建模深入方向。

## 本轮执行判断

> [!note]
> 本节是对 Wu 2019 数据的工程分析，不是用户偏好或已经验证的通用参数。

- 表 5–8 没有过渡段部件 ON/OFF 同史对照，连续瞬态列又是不同旋翼相位的瞬时样本，因此不能从本篇识别“纯旋翼—机翼气动干扰系数”。
- 在 TA=$10^\circ$–$45^\circ$ 的当前算例样本中，两种方法给出的旋翼推力系数和扭矩系数主要表现为相对比例差异，因此可用比例偏差检查简化模型的敏感性。
- 某些倾转角下，机翼升力系数和俯仰力矩系数本身很小，而且两种方法可能给出相反符号。此时用百分比描述差异会失真，应直接比较系数差，并把正、负差值都纳入加性扰动测试。
- 这些数值保持 L1/candidate，仅用于简化建模和鲁棒性敏感性研究，不用于跨构型气动数据库、配平定量设计或认证。

## 影响范围

- 当前 Wu 2019 中文阅读版和定向分析报告。
- 本目录中的阅读偏好候选和 skill 候选。
- 后续其他文献、报告是否采用相同流程，取决于用户确认和第二样本验证。

## 验证计划

1. 用户审核本篇分析报告，指出必须保留、应删去和需要继续展开的内容。
2. 把反馈逐项映射到 D-001 至 D-008 或新增决定，不静默改写历史。
3. 用不同类型的第二篇文献或本篇独立章节进行前向验证。
4. 只有在多样本下仍有效的规则，才建议发布为稳定工作区 skill。

## 已裁决问题

1. 中文文献默认采用完整中文阅读版与定向分析双层交付。
2. 当前停留在机理、模型结构和知识留存，不做 MATLAB/Simulink 实施。
3. 倾转运动项和载荷频率解释做辅助审计，不升为核心逻辑。
4. 控制律价值分析深入到时间尺度、通道、架构、不确定度和验证工况，但不无证据地给出定量控制参数。
5. 当前模型以转周平均或缓慢变化载荷为主体；高频旋翼阶次载荷作为已知但默认省略的效应记录，命中特殊用途时再展开。

## 仍待前向验证

- “完整中文阅读版”对低价值快速筛选文献是否需要显式例外；当前没有自行扩大例外。
