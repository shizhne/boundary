# US12391364B2 单源证据

当动力、飞行包线或作动器能力限制同时执行空速与爬升指令时，专利用约束、饱和检查和权重确定优先级，修正指令并交由后续控制层执行。

## 适用条件

实施例为过驱动、带独立升力及倾转推进单元的电动航空器。两次饱和检查和外环加权替代实施例具有不同的模块分工。局部雅可比回算需在适用构型及工作点使用。用于限值的空速、俯仰、倾转角等量应对齐坐标与参考方向。

| 原文披露 | 锚点 |
|---|---|
| 外环将纵向与垂向加速度映射为俯仰、力需求，再检查限值内可实现响应 | 图12–13、栏24–27 |
| 内环分配按倾转、转矩及效应器限值回算力与力矩 | 图14、栏27–28、式（1） |
| 对低优先级指令施加差量，或依据连续权重修正两个分量 | 图15–18、栏28–34 |
| 当前空速恒定时，最低空速上移也会改变空速优先级 | 图17C、栏31 |
| 外环优化使用构型、发动机状态及约束；可使用局部雅可比伪逆和二次规划 | 图20、式（3）–（4）、权利要求20、24–26、28–30 |

图18的80%纵向、20%垂向修正属于爬升优先的说明性比例。对固定的 $J$ 和 $v_{cmd}$，Moore–Penrose 伪逆乘积有确定结果。原文将多解写在式（4），工程复现应把多解讨论落在局部映射的零空间或可行解集合。式（2）的 $F_{z,ref}$ 保留印刷下标，邻文对回算力的描述也保留。两项均在定向分析解释。

专利公开权重逻辑和算法选项，可作为过渡路径的约束执行接口线索。现有披露未提供完整的空速—倾转角走廊图、目标函数、权重标定、最坏求解时延、闭环稳定性或实飞验证。用于工程复现前需核定力和姿态参考、雅可比量纲、饱和位置及无解时的回退。
